Rebound

Bounce List Manager for Okta

Current Release
v1.2.1

What this does

Rebound adds an operations panel inside the Okta Admin Console. It helps admins search, review, export, and clear bounced or deferred email addresses from the suppression list so users can receive email again.

How to use

  1. Log in to your Okta Admin Console.
  2. Open an admin dashboard URL such as *-admin.okta.com.
  3. The Rebound panel appears automatically.
  4. Search a time range, select addresses, and remove them from the list.
