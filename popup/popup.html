What this does

MOT adds a professional operations panel inside the Okta Admin Console. The current tool helps admins search, review, export, and remove bounced or deferred email addresses.

How to use

  1. Log in to your Okta Admin Console.
  2. Open an admin dashboard URL such as *-admin.okta.com.
  3. The MOT panel should appear automatically.
  4. Use Bounce Email Manager to search and remove bounced emails.
